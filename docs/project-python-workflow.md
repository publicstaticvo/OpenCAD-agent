# Python 工程工作区实施约定

## 数据与执行

项目包含相对路径文件、显式目录和执行入口。沿用 SQLite 源码版本服务：工作副本可以修改，源码快照不可变。快照保存全部文件、目录、入口、父版本、修改者与时间；每个文件有内容哈希，整体快照也有哈希。兼容既有单文件历史时，将 `script.py` 作为入口，原有版本身份保持可读。

编辑器缓冲区由浏览器逐文件保存状态。普通保存只更新工作副本；运行、检查点和 Agent 修改冻结完整快照。Agent 使用 Pi 文件工具的现有编辑实现，通过项目文件适配器操作受限相对路径，补充目录查询、删除、移动和入口选择。工作副本条件更新与不可变分支保留并发源码；用户未保存编辑不会阻止对话。独立设计新增模块并选择入口，修改任务明确使用指定快照和基础模型。

PythonSession 从指定快照读取全部源码，Worker 将完整工程只读挂载至隔离环境，入口通过 bundled Python 显式编译执行，模块路径包含工程根目录；`.FCMacro` 按明确的 Python 源码入口执行。现有 FCStd 独立重开、STEP 重新导入、GLB 与几何检查保持有效。执行身份包含快照身份及哈希，执行目录保存完整输入；正式交付清单包含对应工程快照。

## 用户与 Agent

用户运行直接授权本次指定快照执行，不调用模型、不显示计划审批。健康和交付检查成功后显示候选模型；用户明确验收后才生成正式修订。没有任务特定条件时，报告只承诺健康及交付检查，通过人工验收记录提交授权。候选拒绝、失败、取消和过时基础修订均不更新正式模型。

Agent 对话不因未保存缓冲区或历史查看而禁用。执行使用明确的已保存工程快照，新增独立设计保留无关文件；模型修改使用当前正式基线。普通文本任务不产生重复原话的审批弹窗；明确要求计划审批的任务保留审批。候选默认等待用户验收，显式自动验收授权单独记录。保存、运行授权、候选验收各自记录。

## 实施任务与验证

- [x] 扩展现有源码服务为完整工程工作副本和快照：路径边界、条件保存、无变化复用、逐文件 Diff、旧数据恢复。
- [x] 接通完整工程的隔离执行：单 `.py`、`.FCMacro`、模块、package、相对资源、错误、取消及不执行入口的失败检查，使用真实 FreeCAD 验证。
- [x] 分离直接运行和 Agent 流程：候选等待验收、验收/拒绝幂等、基础修订保护、历史批准不能重新执行、服务重启恢复。
- [x] 扩展 Agent 文件适配与任务上下文：多文件创建、精确编辑、删除、移动、入口、修改来源、用户并发分支；使用确定的 Agent 工具响应序列及真实 Worker 验证。
- [x] 增量扩展 CodeMirror 工作区：文件树、标签页、独立缓冲区、保存全部、历史快照浏览、文件 Diff、恢复、ZIP/目录导入导出、本地授权另存为。浏览器原生授权操作尚未人工验收。
- [x] 项目选择、最近项目、名称搜索；统一活动与真实执行状态；历史模型查看保持聊天可用；沿用四种布局与单一模型导出菜单。
- [x] 更新 P/C/E/U 自动化和人工验收矩阵，执行回归、原生 CAD 与浏览器检查，保存截图和文件。未执行的人工及在线项目明确记录；类型检查的既有 SDK 接口问题标记为 BLOCKED。

## 关键检查

路径禁止绝对路径、父目录、链接和规范化后歧义；ZIP 使用成熟库，限制展开大小、重复路径与条目类型。执行只读取冻结输入，工作文件变化不影响执行。异步结果按执行身份处理；候选采用检查项目、基础修订、快照、验证与交付清单。历史浏览不会触发执行，候选验收不会隐式改写当前编辑缓冲区。

实现进度及实际测试结果记录于 `docs/testing/source-workspace-and-activity-timeline.md`。本文件中的任务复选框表示实施进度，不表示尚未执行功能已可用。

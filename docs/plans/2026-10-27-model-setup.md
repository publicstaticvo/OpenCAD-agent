# 在线模型配置

网页在工作区认证之后提供 baseUrl、API key、模型选择。服务端查询兼容 OpenAI 的模型列表，解析服务提供的上下文和输出限制，并复用 Pi 模型目录中的匹配配置。无法确定上下文时使用 262144 tokens，自定义模型的单次输出默认使用 Pi 的 16384 tokens；实际请求由 Pi 根据剩余上下文调整。费用显示未配置。

模型密钥保存在服务端私有配置文件中；公开配置不包含密钥。保存时自动生成 approved.json。保存配置之前核实模型列表，失败保持已有配置。每个任务开始时固定当前模型配置，中途修改配置只影响之后开始的任务。

实施顺序：配置解析与持久化测试；真实模型传输与 Gateway 接口；网页配置入口；真实服务上的网页配置、创建、修改、文件下载与重新打开测试；启动说明和回归检查。测试使用用户提供的 model.yaml，结果中不记录密钥。
